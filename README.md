# NitroCode — releases

Instaladores oficiais do NitroCode e o manifesto de atualização (`latest.json`).
O código-fonte é privado; este repositório contém apenas artefatos publicados.

- **Windows:** `NitroCode_<versão>_x64-setup.exe`
- **Debian/Ubuntu (incluindo WSL):** `nitrocode_<versão>_amd64.deb`

Todo artefato é assinado (minisign). O NitroCode recusa qualquer atualização cuja
assinatura não confira com a chave pública embutida no app.
